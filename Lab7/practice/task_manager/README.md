# 📌 Task Manager CLI (Python)
> A simple and practical Command-Line Task Manager built with Python.
This project demonstrates core programming concepts including OOP, file handling, modular structure, and CLI interaction.

🚀 Features
- ✅ Add new tasks
- 📋 View all tasks
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Persistent storage using JSON
- ⚠️ Error handling for invalid input
